# 📊 Swiggy Sales Dashboard

## 📌 Project Overview

This project is an interactive Swiggy Sales Dashboard created using Microsoft Power BI.

The dashboard provides meaningful insights into sales, orders, restaurants, food categories, customer ratings, and locations.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing restaurants and food categories
- Analyze customer ratings
- Understand location-wise performance
- Track important KPIs
- Create interactive visualizations for business decision-making

## 🛠️ Tools & Technologies

- Excel 
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard


## 🔍 Key Insights

- Analyzed overall sales and order performance
- Identified top-performing categories
- Compared restaurant performance
- Analyzed customer ratings
- Studied location-wise trends
